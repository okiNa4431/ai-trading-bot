# JP-1：日本株の合成仮想売買MVP

2026-10-21。[日本株設計・ロードマップ](japan-roadmap.md)を基準とする。**SYNTHETIC / Gemini mock / 実市場の運用実績ではない。**

## 実行

```powershell
uv sync --locked
uv run python scripts/japan_synthetic.py
```

APIキー不要。新規一時SQLiteにのみ仮想口座を作り、終了時削除する。生成器の架空ID `synthetic:jp:0000` と架空ティッカー `JPTEST0000.T` は実企業・取引所コードに対応しない。既存の米国株MVP、実データWorkflow、Supabase、API履歴は変更しない。一般取得停止ゲートの解除はない。

## 実装と再利用

- `japan_synthetic.py`：専用JPX生成器、合成財務4因子のmock評価、構造化JSON検証、日次履歴、合成NAV。
- `FinancialScore`：成長性・収益性・健全性・競争力、理由・リスク・証拠、公表/取得/判断時刻。extra禁止、未来証拠禁止。数量・価格の出力欄はない。実Geminiは呼ばない。
- 品質は既存ReviewFact/QualityAssessmentで明示。合成生成契約の同一性・企業行動なしは実証券へ転用できない。欠損・重複・35%超不連続・未確定・証拠不足は停止、保有の強制評価・解消はしない。
- 既存 `signal` を使用：SMA20/60、20日高値、損切り8%、トレーリング12%、保有30営業日。設定は `config/japan-synthetic.yaml`、`timing` の既存MVPSettingsのシグナル項目で変更可能。US専用の生成設定や内包rulesは使用しない。JP売買コストはトップレベルrulesが唯一の設定。
- 既存PaperBroker、JPXセッション、Decimal台帳、`estimate`、評価・リスクを再利用。100株、1銘柄10%・全体80%・現金20%、最大8保有、目標9%。上昇による事後の比率超過は記録し買い増しを停止する。機械的なリバランスは行わない。
- 手数料55円/約定・スリッページ0.1%は検証用仮定。現実の証券会社の料金ではない。円だけを扱いFX交換なし。
- 注文は終値確定後、後続JPX営業日の始値で歴史的模擬約定。処理自体は後続バーの確定後。最終日の後続バーがなければPENDINGのまま。未約定BUY予約を予算に反映し、未約定SELLを買付資金にしない。
- 財務mockは実行開始前の架空公表情報で固定選定。保有は選定外でも評価する。後日の価格・情報で過去注文を変更しない。実市場の投資可能母集団やAIの選定能力は検証していない。

## 合成NAVの契約

オルカン実NAV型・公式Providerは変更していない。独立した合成NAVは1万口当たり。両口座の開始は同じ2024-04-03終値後、模擬申込適用は翌JPX日2024-04-04のNAV。公表前は評価に利用しない。口数は整数切捨て、残金を保有。適用まで現金100万円。販売会社の実際の申込不可日・締切・海外休日は表現しておらず、実投信の取引検証ではない。欠損NAVは補完しない。
