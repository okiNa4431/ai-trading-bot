# J-Quants API V2 Free：仕様・利用条件レビュー

確認日：2026-10-21（公開公式資料のみ）。JP-2は個人の私的投資分析に向けた読取準備であり、学術研究・第三者向けサービスではない。実API呼出しは0回。ユーザー固有の契約・Free加入状態は未確認。

| 項目 | 確認結果・根拠 |
|---|---|

| Free期間 | [プラン別仕様](https://jpx-jquants.com/ja/spec/data-spec)：12週間前〜2年12週間前の2年分。最新相場を使うフォワード運用はできない |
| Free対象 | 同資料：上場銘柄一覧、日足、バリュエーション、財務情報、取引カレンダーなど。TOPIX・詳細財務諸表・配当金情報はFree対象外。Freeの株価CSV/Bulkは利用しない |
| 無料・登録 | [クイックスタート](https://jpx-jquants.com/ja/spec/quickstart)、[公式FAQ](https://jpx-jquants.com/ja)：ユーザー登録とFree購読が必要。Freeにカードは不要。有料プラン・アドオンへ移行しない |
| レート | [公式上限](https://jpx-jquants.com/ja/spec/rate-limits)：Free 5回/分、アカウント単位。他のキー・端末の利用分も合算。システム状況で変更され得る |

| ページング | [公式仕様](https://jpx-jquants.com/ja/spec/pagination)：`data`と`pagination_key`。同条件でキーを引き継ぎ、空/不在まで取得。公表された固定ページサイズは確認できず、件数から完了を推測しない |

2026-10-21時点の公式窓は概ね2024-07-29〜2026-07-29。本実装は両端1暦日の余裕を設け、閏日付近の2年計算も保守側を選ぶ。研究範囲は **2025-01-06〜2025-12-30で固定**。実行日から範囲をずらさず、窓から外れたら通信前停止する。確認の有効期限は2026-11-20とし、それ以降は仕様・規約を再確認してコミットするまで停止する。これは当Botの安全制限であり公式の追加制限ではない。

## 用途・保存・公開の区別

[利用規約](https://jpx-jquants.com/ja/termsofservice)第5〜8条と[利用目的FAQ](https://jpx-jquants.com/ja/help/usage)を根拠とする。

| 用途 | 判定・JP-2での扱い |
|---|---|
| 個人の私的な分析・バックテスト・ポートフォリオ管理 | 許容される用途。法人・一般の学術研究は別扱い。個人登録・購読と規約同意をユーザーが確認する |
| 本人だけが閲覧するローカル・外部クラウド保存 | 契約中はFAQ上可能。アクセス制御等は本人責任。JP-2では保存しない |
| GitHub-hosted Actionsの一時メモリ処理 | GitHub名指しの許可は未確認。本人管理のクラウド・本人以外への非開示というFAQ条件に具体的運用が適合するかを確認する。コード公開は実データ配布と分離。実行前の契約確認と別承認が必要 |
| Supabase等の外部DB | 上記条件と削除・バックアップ管理が必要。今回は実装・保存・migrationなし。別承認対象 |
| 生データ・復元可能な加工指標の第三者配布 | 禁止。公開ログ、artifact/cache、Pages、共有DBへ出さない |
| 一回の分析手法・結果の共有 | FAQで許容例あり。ただし非復元性等を確認せず一般化しない。JP-2で成績は計算・公開しない |
| 投資分析結果を継続反復して公開・提供 | 私的利用に該当しない旨が明記されている。将来の継続的な実運用ダッシュボード公開を許可済みと扱わない |
| 外部AI・EDINETへのデータ送信 | 今回禁止。一般のクラウド保存許可から学習・保持を伴うAI転送許可へ拡張しない |

契約終了後は規約第7条に従い本データ・複製物を廃棄する。FAQは解約/ダウングレード後の復元可能な派生物も削除対象としている。非復元派生物の保持例外も外部公開の許可ではない。Freeは規約上1年後に自動解約されるため、将来保存する場合は購読期限・バックアップの削除も管理する。固定の永久保持権はない。価格・規約・APIは変更され得るので、現行規約とリリースを再確認する。有料化を自動承認する処理はない。

## 調整・企業行動・過去時点の制約

[日足仕様](https://jpx-jquants.com/ja/spec/eq-bars-daily)、[調整計算](https://jpx-jquants.com/ja/spec/eq-bars-daily/adj)、[リリース](https://jpx-jquants.com/ja/spec/release)を確認した。

- `O/H/L/C/Vo/Va`と`AdjO/AdjH/AdjL/AdjC/AdjVo`を分離し、APIの値を調整・補完しない。調整済み値は後続イベントで遡及更新されるため、歴史的判断時点の値だと主張しない。訂正前の配信事実は今回復元できない。
- `AdjFactor`は正の有限値を検証。`ExRT`は全プランの追加項目（2026-08-10公表）。1=分割、2=併合、3=ライツ、該当なしはNull。係数と区分の矛盾・未知区分・係数だけの変化は異常/UNKNOWNとして保持する。
- 現金配当や全種類の分社化等はこの調整だけでは扱えない。ライツの出来高は調整対象外。係数・区分が一致しても、保有株数・現金・取得原価の会計処理は未検証。
- 無約定日はOHLC/Vo/VaがまとめてNullの行として返り、理由を区別するステータスはない。欠損行とは別計数し、補完しない。Nullを取引高0に置き換えない。
- 行の利用可能時刻は本Botの取得時刻を上限 `observed_by` とし、提供元公表時刻はUNKNOWN。JPX終了時刻と照合する。公式カレンダーAPIは今回追加せず、既存JPXライブラリと固定営業日集合を利用する。
